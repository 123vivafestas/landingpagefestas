123 VIVA FESTAS — SITE PRONTO PARA HOSPEDAR

ORGANIZAÇÃO
  index.html ........ a página
  robots.txt ........ orienta o Google
  sitemap.xml ....... mapa do site para o Google
  .nojekyll ......... arquivo técnico do GitHub Pages (não apague)
  img/
    marca/ .......... logo
    temas/ .......... fotos dos kits por tema
    personalizados/ . painéis personalizados
    estilos/ ........ Essencial, Premium e Festa Compacta
    sobre/ .......... Kamilla, festa no parque e o GIF da caixa

ANTES DE PUBLICAR
  1. Em index.html, robots.txt e sitemap.xml, troque SEUDOMINIO.com.br
     pelo endereço real do site, com a barra no final.
  2. Em index.html, troque LATITUDE e LONGITUDE pelas coordenadas do
     endereço (Google Maps > botão direito no ponto > copiar os números).

COMO SUBIR NO GITHUB
  Descompacte. Em "Add file > Upload files", arraste o index.html, os
  outros arquivos E a pasta img inteira (arrastando a pasta, e não
  selecionando os arquivos um a um, o GitHub mantém as subpastas).
